# 此刻，正好｜富達四十週年晚宴

靜態線上邀請函，部署於 GitHub Pages。主檔為 `index.html`、`style.css`、`script.js`，不需建置工具。

## 2026-11-22 依 PPT 更新（v22）

依使用者提供的「此刻正好_富達四十週年晚宴邀請函_Canva可編輯.pptx」六頁內容與視覺修改。保留 PPT 原始背景、牛皮紙信封、繩扣、銀色封印、郵票、淺藍票券、信紙與男女穿搭拼貼，素材位於 `assets/ppt-v22/`。文字轉為可選取的 HTML，以原始投影片位置、旋轉角度、配色與字級比例排列。為延續既有需求，網頁文字使用內嵌朱雀仿宋粗體，原圖中的文字保留原貌。

開場可點銀色封印或「入學通知・請親啟」開函，使用淡出轉場進入通知書並播放使用者提供的 Lovely Day。頁首 Logo 與導覽同行，捲動後選單置頂。21:00 更新為「相聚有時・精彩落幕 / A Grand Finale」。穿搭改為「復古學院風」，女士與男士各五款，新增條紋領帶、菱格針織、撞色 V 領毛衣、鞋款與銀色飾品指南。

穿搭圖可在原頁放大，文字密集頁有「放大閱讀」，不跳頁。為相聚喝采按鈕顯示可見祝福文字，一般模式另有紙花動畫；尊重減少動態設定。

活動：2027 年 1 月 8 日（星期五），18:00 迎賓、19:00 開席、21:00 精彩落幕。地點：南港六福萬怡酒店 9F 水晶雲風光，台北市南港區中南里忠孝東路七段359號。飯店名稱可開啟 Google Maps。

`assets/lovely-day.mp3`、官方 Logo 及 PPT 背景由使用者提供。其他舊版素材仍保留在 assets，供歷史版本使用。朱雀仿宋字型來源：https://github.com/TrionesType/zhuque ，授權見 `assets/FANGSONG-LICENSE.txt`。新增中文字後須更新字型子集。

信封月桂章、郵票、銀色封印、通知書紀念章、票選文案、佈置主背板與道具、頁尾紀念章，統一使用原官方 Logo 右上角的 40 Years 圖形。金色與銀色 SVG 使用同一個原始圖像來源與視窗，僅變更單色填色，保留相同輪廓和比例。銀色版本位於 `assets/anniversary-40-years-silver.svg`。
