# 此刻，正好｜富達四十週年晚宴

純 HTML / CSS / JavaScript 網站，不需安裝套件。所有網址皆為相對路徑，可直接放在 GitHub Pages 專案子目錄。

## 預覽

在本目錄執行 `python3 -m http.server 8080`，開啟 http://localhost:8080。

## GitHub Pages

將此目錄內容放到 `Fidelity-International-40th` repository 根目錄。Settings → Pages → Deploy from a branch → main → / (root)。

## 修改內容

- `index.html`：活動文字、日期、流程、圖片。
- `style.css`：酒紅色系、版面、信封動畫及手機樣式。
- `script.js`：開函與音樂控制。配樂只在使用者點擊後播放。
- 飯店交通圖：以 `<img src="assets/hotel-map.jpg" alt="飯店交通圖">` 替換 `.map-placeholder`。
- 圖片取自提供的企劃 PDF，為概念示意。Logo 為提供圖片上方紅色品牌款，保持原色及比例。
- 配樂為使用者提供的 Lovely Day MP3；未附歌詞。
- 18:00 與 19:00 為企劃已確認時段；其餘時段與票選規則已標註待確認。

## 檔案

`assets/lovely-day.mp3` 為網站配樂。未包含來源影片、完整企劃 PDF 或本機路徑。

## 互動與動態

開函時播放配樂並飄落 40 片彩紙；頁尾「為相聚喝采」可重播彩紙。流程、標題與相片進入畫面時依序出場。遵循裝置的減少動態效果設定，停用彩紙與位移動畫。

## 布藝版本

視覺改為酒紅織紋、米白亞麻、縫線標籤與刺繡祝酒主圖。`assets/embroidered-cheers.webp` 使用內建圖像生成工具製作，提示為「米白毛邊亞麻上的酒紅刺繡碰杯圖，緞帶繡 40，酒紅織布底，限酒紅與米白，無其他文字」。`red-linen.webp` 與 `ivory-linen.webp` 為同張圖的材質裁片，`stage-concept.svg` 為原有佈置示意的酒紅線稿版。圖片只作活動視覺概念。

## 滿版信封與仿宋字型

開場信封填滿視窗，只有「40 同行」封蠟按鈕可開函，支援鍵盤 Enter / Space。所有網頁文字統一使用朱雀仿宋，字型依頁面所需字元製成 WOFF2，隨網站載入，含全部使用中的繁體字。原始字型：https://github.com/TrionesType/zhuque ，SIL OFL 1.1 授權見 assets/FANGSONG-LICENSE.txt。新增文字時，應重新產生子集。圖片內原有文字與官方 logo 為原始素材的一部分。

## 固定構圖開場

網站與開場最大寬度 1100px。信封以固定 1100 × 1000 構圖呈現：初始只看信封封口特寫，點擊「40 同行」才先縮放到完整信封，再掀蓋抽出信紙，最後顯示邀請函。內部尺寸固定，手機依視窗裁切特寫並等比縮小完整畫面。動態依裝置減少動態設定停用。

## 通知函內容與置頂選單更新

中英文網頁文字以嵌入式朱雀仿宋搭配 700 粗體與字重合成顯示。置頂懸浮選單整合晚宴、流程、穿搭、亮點、音樂播放暫停與音量滑桿，圖示為原生 SVG。晚宴資訊採年月日分欄、場地與地址排版；流程更新為 18:00 / 19:00 / 21:00 三段。原手拿牌與紋身貼紙圖片區塊已移除。圖片中既有文字與官方 logo 保留原始素材。

## 頁首與音樂開關

第一屏為 Logo 與選單同行的頁首；捲動超過 24px 後切換為置頂懸浮選單，回到頂部還原。手機第一屏以 SVG 音樂開關節省寬度，懸浮時顯示開關文字。音量調整圖示與滑桿已移除，只保留「開啟音樂／關閉音樂」按鈕，依實際播放、暫停、靜音狀態切換 SVG 與輔助標籤。

## 銀色封蠟與蕾絲封口（v14）

首屏使用酒紅紙紋與真實蕾絲封口，銀色橢圓封蠟以右上角 40 Years 週年標誌製作浮雕。點擊封蠟才展開完整信封與邀請函。封蠟按鈕支援鍵盤與減少動態設定。

素材使用內建 image_gen 製作，儲存於 assets/envelope-portrait-v14.png 與 assets/silver-seal-v14.png。提示：依參考圖製作滿版酒紅皮紙、V 形蕾絲封口，不含手機與文字；另製透明背景銀色橢圓封蠟，以右上角 40 Years 標誌為銀色浮雕，不含 F 圖案、花朵與紅色標記。
